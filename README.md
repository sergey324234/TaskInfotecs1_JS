# Автотестирование командной строки chmod 

## Описание реализованных тест-кейсов

1) Установка прав на файл (только числа)
2) Изменение прав на файл (+-= только числа)
3) Изменение прав на файл (+-= только символы, 1 режим)
4) Изменение прав на файл (+-= только символы, несколько режимов)
5) Тест опций chmod (рекурсивное изменение вложенных папок и файлов)
6) Тест опций chmod (копирование прав с одного файла на другой)
